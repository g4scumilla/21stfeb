Privacy Policy

Effective Date: November 17, 2026

1. Zero Personal Data Collection

My Store (both the Android application com.mystore.app and this GitHub Pages website) does not collect, sell, track, or transmit personal information, analytics, advertising identifiers, or user accounts.

2. Network Requests & GitHub Infrastructure

The Android app connects solely over HTTPS to the GitHub Pages catalog URL you configure and the corresponding GitHub Releases APK URLs. Standard web server logs (such as IP address and user-agent) may be processed by GitHub Pages / GitHub Releases under GitHub's own Privacy Statement.

3. Package Visibility & Update Detection

To detect updates for applications listed in the catalog and for My Store itself, the Android app checks installed version codes locally on your device using Android's least-privilege package visibility rules. Your list of installed apps is never uploaded or shared off-device.

4. Local Storage & APK Verification

Cached catalog metadata, downloaded APK files, download history, and theme preferences are stored locally on your device. You may clear history or uninstall My Store at any time to remove this local data.
