About My Store

My Store is an open, zero-cost Android APK distribution marketplace powered by GitHub Pages, GitHub Actions, and GitHub Releases. Every release is signed consistently and published with a verifiable SHA-256 checksum.

APK Safety Notice

Third-party APKs are independently distributed and have not necessarily been reviewed by Google Play. A SHA-256 checksum verifies file integrity against the catalog's published digest—it does not constitute malware scanning. Always review app permissions before installing.

Contact & Support

For bug reports, release inquiries, or takedown requests, please open an issue on the public GitHub repository hosting this My Store catalog.
